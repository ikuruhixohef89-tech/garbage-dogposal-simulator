# Garbage Dogposal Simulator

A tiny cooking game for [Vibe Games](https://www.vinceandbyte.fun). Slice produce mid-air and share the right scraps.
The garbage disposal is a chihuahua named Crumb. Anything that is not for dogs gets caught by the SOUS-AI safety mitt.

Plain JavaScript modules, Canvas 2D and Web Audio. No libraries, no build step, no external requests.
All graphics and sound are generated by code.

## Run locally

Requires Node 20+. Nothing to install.

On Windows, double-click `play-local.cmd`: it starts the server in its own window (close it to stop) and opens the game.
Or from a terminal:

```
npm run serve
```

- Game: http://localhost:8080/garbage-dogposal-simulator/
- Debug overlay: add `?debug=1`
- Cross-site iframe test (like the real site): http://127.0.0.1:8081/

ES modules do not load from `file://`, so always use the server. Opening `index.html` directly shows a notice instead of the game.

## Checks

```
npm test        # unit tests: layout, RNG, rules, blade, shifts, perf, session
npm run check   # brief rules (no external URLs, cookies, absolute paths; lowercase names; weight <= 300 KB)
                # and the dog-safety check (nothing toxic or "not food" is ever eaten)
```

## Dev tools (not loaded by the game)

- `tools/dog-sandbox.html` — Crumb's angles, silhouette, sizes and all expressions.
- `tools/capture.html` — renders the site images into `site/` (1280x720 JPEG).
- `tools/embed-test.html` (port 8081) — the game in a cross-site 16:9 iframe.
- `?debug=1` on the game — frame stats and `window.__gds` hooks.

## How to play

Two modes.

**Sort & Feed** (the main mode, the big Play button). SOUS-AI tosses produce into the air; swipe through it to slice.
The pieces land on the tray, and you send each one: the plain spare bit to Crumb, the sliced pile to the bowl,
peels, pits, ends and anything not for dogs to the bin. Flick or drag a piece to its target, or tap it and then tap the target.
Anything unsafe thrown at the dog is caught by the SOUS-AI mitt (a strike for toxic parts).

**Slice Rush**. Only slicing: halves go to the bowl, scraps to the bin, and a spare bite flies to Crumb on its own.

In both: items with a red octagon (onion, grapes, chocolate, garlic, sugar-free gum) are not for dogs, let them fall;
slicing one is a strike, three strikes end the shift. Frozen produce slows time, golden produce is worth +50, the squeaky
ball gives zoomies. After Monday and Wednesday you pick one of three upgrade cards (for this run only). Small events happen:
hiccups, a sneeze, a delivery, and a jammed unit that is cleared by petting Crumb three times.

**Records and skins.** Each level (MON, WED, FRI) and the whole run keep your top 5 scores per mode, on this device only.
Skins for Crumb (bandana colors and hats) unlock when your best run score passes a threshold. Nothing is bought.

## Controls

| Action | Mouse / touch | Keyboard |
|---|---|---|
| Start | Play (Sort & Feed) or Slice Rush | Enter / Space (Sort & Feed) |
| Training | Training on the title (replays the tutorial, then the first shift) | — |
| Slice | Swipe across the produce (mouse: hold the button) | Space (assist: slices the lowest produce, never a bomb) |
| Send a tray piece | Flick or drag it to the dog, bowl or bin; or tap it, then the target | Q / E pick, 1 / 2 / 3 send to dog / bowl / bin |
| Pet Crumb | Tap the dog | — |
| Pick an upgrade | Tap a card | 1 / 2 / 3 |
| Pause | Pause button | P (Esc also works) |
| Sound | Sound button | M |
| Hide UI | Pause > Hide UI (double-tap the top-left corner to bring it back) | H |
| Fullscreen | Fullscreen button | F |
| Restart | Pause > Restart, or Again on the report | R (while paused or on the report) |
| Main menu | Pause > Main menu, or Main menu on the report | — |

## Structure

```
index.html        entry point, all paths relative
src/              game code (loaded by the browser)
  core/           loop, layout, viewport, input, storage, rng, math, perf
  render/         baked layers and kitchen background
  audio/          Web Audio engine
  ui/             DOM overlays, icons, CSS
tools/            dev server, checks, tests, embed test (not loaded by the game)
site/             material for the Vibe Games page (not loaded by the game)
```
